Which kind of files to search. Exactly one scope is searched per call; there is no "both". "code" (the default when you omit this parameter) searches source files plus config/data/markup files (.rs, .py, .ts, .json, .yaml, .html, .css, ...); use it for questions about how something is implemented, where it lives, or who calls it. "docs" searches prose documentation only, meaning files whose extension is in the configured docs list (by default .md, .mdx, .rst, .txt) such as READMEs, design notes, guides and changelogs; use it for why/convention/setup/spec/decision questions. Docs are NOT included unless you pass "docs". If the chosen scope has no results at all, the other scope is searched once and the output begins with a [scope fallback] note saying so; pass an explicit scope to search one class directly.
